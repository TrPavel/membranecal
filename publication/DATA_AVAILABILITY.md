# Data Availability

The MembraneCal v0.2 reproducibility materials, distributed as repository/package
release v0.2.0, are available at https://doi.org/10.5281/zenodo.22843162 and
https://github.com/TrPavel/membranecal. Cite the exact package release used.

The package includes compact frozen inputs, source identifiers and checksums,
scientific code, derived tables, manuscript and figures. Compact offline replay
verifies coordinate-derived scores; full replay reproduces the frozen scenario
estimates, bootstrap checks, nine tables and five figures. Replay requires no
private research checkout, GPU inference or raw upstream download cache.
Dependency installation requires a package source. Historical raw-resource
reconstruction is a separate operation requiring the identified historical source
bytes; current downloads cannot substitute for the original freeze. Raw upstream
resources are not redistributed in full.

Author-created code is Apache-2.0, authored text/figures CC BY 4.0, and third-party
materials retain source-specific terms. The author's scoped OPM permission covers
the numerical values described for this reproducibility package, with attribution
and provenance. It does not cover arbitrary raw OPM database redistribution.

This is the current Data Availability statement for the release. It supersedes
earlier no-DOI/planned-deposit wording in the preserved historical manuscript and
receipts, which remain byte-identical for provenance. It does not claim journal
publication or peer review and does not alter the frozen scientific manuscript.
