# Security and sensitive information

Report suspected credentials, sensitive-data exposure or unsafe archive handling
privately to the maintainer at **trofimchikpavel@icloud.com**. Do not publish the
secret or private dataset in an issue. Include the affected version and a safe,
redacted description. This project provides no guaranteed response SLA.

Install only reviewed dependencies in an isolated environment. Replay does not
require credentials, cloud compute or a running external service. Scientific
limitations and unexpected benchmark results belong in scientific issues rather
than vulnerability reports, unless they expose a security defect.
