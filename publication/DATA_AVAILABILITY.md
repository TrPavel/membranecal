# Data Availability — current draft

The MembraneCal v0.2 reproducibility package has reserved Zenodo DOI
**10.5281/zenodo.22843162**. The record remains a **draft** and is not yet publicly
available. The dedicated GitHub repository is in **private release-candidate
staging**. This is not a statement that a published deposit or article exists.

The candidate includes compact frozen inputs, source identifiers and checksums,
scientific code, derived tables, manuscript and figures. Numerical replay requires
no private research checkout, GPU inference or raw download cache. Historical
raw-resource reconstruction is a separate operation requiring the identified
historical source bytes; current downloads cannot substitute for the original freeze.

Author-created code is Apache-2.0, authored text/figures CC BY 4.0, and third-party
materials retain source-specific terms. The author's scoped OPM permission covers
the numerical values described for this reproducibility package, with attribution
and provenance. It does not cover arbitrary raw OPM database redistribution.

This administrative draft supersedes earlier no-DOI/planned-deposit wording in
the preserved historical manuscript/receipts. After separately authorized publication,
verify public access and update the final journal availability statement. No
submission manuscript is silently rewritten by repository staging.
